Jeron v3 - مشروع أندرويد (WebView)
البناء: Android Studio (Build APK) أو GitHub Actions (ارفع المجلد > Actions > Build APK).
الواجهة: app/src/main/assets/index.html

الجديد بالنسخة 3:
- 3 مفاتيح OpenRouter مضمّنة، وإذا خلص حد مفتاح ينتقل للتالي تلقائياً. تضيف مفاتيحك من الإعدادات (واحد بكل سطر).
  تنبيه: المفاتيح داخل الـAPK؛ لا تنشر المستودع/الـAPK علناً.
- نموذج خارجي (Gemini أو غيره): ملف app/src/main/assets/custom_model.js  +  GEMINI_MODEL_PLUGIN.md
  انسخ GEMINI_MODEL_PLUGIN.md لـ Gemini وانطيه اسم النموذج ووثائقه؛ هو يكتب لك الملف. أو الصق الكود من الإعدادات > نموذج خارجي.
  بعدها اختر "مخصص" بدل عادي/برو (كلام/صور/فيديو) أو كمحرك صوت.
- "مجلس النماذج" (الإعدادات): عدة نماذج قوية تجاوب ونموذج يدمج أفضل جواب. أقوى، لكن يصرف 4 أضعاف الرسائل.
- المحادثة الصوتية: تظهر الأخطاء بدل الصمت، وإذا جهازك ما عنده صوت عربي يجرب صوت OpenRouter.
  عينة الصوت: ترفع صوت أو فيديو (نستخرج صوته) من الإعدادات > الصوت، ويستعملها محرك TTS يدعم الاستنساخ (سيرفرك / ElevenLabs / نموذج خارجي).
- حُذف: وضع البرمجة، المعاينة/ZIP للمشاريع، العملاء/الاستوديو، 3D.
- ai_projects/: كود Qwen3 وQwen-Image وWan2.1 الرسمي + jeron_gateway.py لتشغيلها على جهاز GPU عندك وربطها بالتطبيق (اقرأ ai_projects/README.txt).
- بدون نت: نموذج Qwen3 صغير ينزل مرة من الإعدادات ويشتغل تلقائياً.
