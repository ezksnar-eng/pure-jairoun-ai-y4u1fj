Jeron v2 - مشروع أندرويد (WebView) جاهز للبناء
البناء:
1) Android Studio: File > Open > مجلد المشروع > Build > Build APK(s)
2) أو GitHub: ارفع المجلد كاملًا لمستودع > Actions > Build APK > نزّل Jeron-APK
الواجهة كلها بملف واحد: app/src/main/assets/index.html

شنو الجديد:
- نماذج مفتوحة المصدر: Qwen3 (عادي/برو) + Llama 3.3 70B + Hermes 3 405B + MythoMax، صور: FLUX / Qwen-Image، فيديو: Wan2.1 (عادي/برو).
  التبديل الصامت تلقائي عند أي خطأ أو حد، وزر "غيّر النموذج" يدوي، وخيار تدوير النماذج بين رد ورد.
- لازم تضيف مفتاح مزود واحد على الأقل من الإعدادات (SiliconFlow أو Groq أو Hugging Face أو DashScope) - ثلاثتهم عندهم مجاني.
  أو تربط سيرفرك (Ollama/LM Studio/vLLM) من "سيرفرك الخاص".
- بدون نت: نزّل النموذج المحلي (Qwen3 0.6B/1.7B) من الإعدادات مرة وحدة، وبعدها يشتغل تلقائيًا عند انقطاع النت.
- البرمجة: المشاريع تطلع ملفات + بطاقة مشروع (معاينة حية مثل المتصفح / ZIP / الملفات)، الكود الطويل ما يعلّق التطبيق.
- 3D وأنيميشن (Three.js) مع تسجيل الفيلم فيديو، وقسم صوتي: موسيقى ومؤثرات تنتج WAV.
- محادثة صوتية: اضغط أيقونة الموجة. الشخصية تكتبها من إعدادات الصوت. الصوت: صوت الجهاز، أو سيرفر TTS + عينة صوتك، أو ElevenLabs.
- استوديو العملاء: تحدد عدد العملاء والأقسام والمدة (حتى 6 ساعات) ويشتغلون سوا على مشروع كامل ويطلع ZIP.
